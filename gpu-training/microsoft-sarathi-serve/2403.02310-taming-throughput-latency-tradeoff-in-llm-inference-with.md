# Taming Throughput-Latency Tradeoff in LLM Inference with Sarathi-Serve

## TL;DR

Sarathi-Serve is an LLM inference scheduler that uses chunked-prefills and stall-free scheduling to simultaneously achieve high throughput and low latency, significantly outperforming vLLM across various models and hardware configurations.

## Problem & Motivation

LLM inference involves two phases: prefill (high latency, high GPU utilization) and decode (low latency, low GPU utilization). Batching multiple requests interleaves prefill and decode iterations, creating a tradeoff between throughput and latency. Existing systems struggle to maintain low latency while increasing batch sizes for higher throughput.

## Key Ideas

- Chunked-prefills: splitting a prefill request into near-equal-sized chunks to avoid long prefill iterations.
- Stall-free scheduling: adding new requests to a batch without pausing ongoing decode iterations, enabling large batch sizes without latency penalties.
- Uniform batches: reducing imbalance between iterations to minimize pipeline bubbles in pipeline parallelism.

## System Design

Sarathi-Serve is a scheduler integrated into the LLM inference serving stack. It operates by chunking prefill requests into smaller, uniform chunks and interleaving them with decode iterations in a stall-free manner. The scheduler ensures that new requests are added only when they do not interrupt ongoing decodes, maintaining consistent iteration times. For pipeline parallelism, uniform batches reduce pipeline bubbles.

## Evaluation

Evaluated on Mistral-7B (single A100), Yi-34B (two A100s), and Falcon-180B (pipeline parallelism). Baselines include vLLM. Headline results: 2.6x higher serving capacity for Mistral-7B, up to 3.7x for Yi-34B, and up to 5.6x for Falcon-180B under tail latency constraints.

## Takeaways

- Chunked-prefills effectively decouple prefill latency from batch size, enabling high throughput without latency spikes.
- Stall-free scheduling is key to maintaining low latency with large batches.
- Uniform batches improve pipeline efficiency, especially for large models.
- Sarathi-Serve demonstrates significant gains over state-of-the-art systems like vLLM.

## Related Work

Sarathi-Serve builds on prior work in LLM inference serving, particularly addressing limitations of systems like vLLM that suffer from throughput-latency tradeoffs due to prefill-decode interleaving. It introduces chunked-prefills and stall-free scheduling as novel contributions.

## Open Questions

How does Sarathi-Serve handle heterogeneous hardware or dynamic request sizes? Can chunked-prefills be extended to other model architectures (e.g., MoE)? What are the memory overheads of chunking? How does it compare with other schedulers like FastServe or Orca?
