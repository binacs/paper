# Ansor : Generating High-Performance Tensor Programs for Deep Learning

## TL;DR

Ansor is a tensor program generation framework that uses hierarchical search space sampling, evolutionary search, and a learned cost model to automatically generate high-performance tensor programs for deep learning on various hardware platforms.

## Problem & Motivation

Deep learning models rely on efficient tensor programs for execution, but manually writing optimized kernels for different operators and hardware is labor-intensive. Existing approaches either use vendor libraries (requiring significant engineering) or search-based methods that are limited by restricted search spaces and ineffective exploration strategies, often missing high-performance programs.

## Key Ideas

- Hierarchical representation of the search space to sample diverse programs.
- Evolutionary search combined with a learned cost model to fine-tune sampled programs.
- A scheduler to simultaneously optimize multiple subgraphs across a set of neural networks.

## System Design

Ansor first constructs a hierarchical search space that captures a wide range of optimization combinations. It samples programs from this space, then uses evolutionary search guided by a learned cost model to iteratively improve them. A scheduler coordinates optimization across multiple subgraphs in a neural network or across networks.

## Evaluation

Evaluated on Intel CPU, ARM CPU, and NVIDIA GPU with deep neural networks. Achieves speedups up to 3.8× on Intel CPU, 2.6× on ARM CPU, and 1.7× on NVIDIA GPU compared to state-of-the-art approaches.

## Takeaways

- Hierarchical search space enables exploring more optimization combinations than prior work.
- Combining evolutionary search with a learned cost model effectively identifies high-performance programs.
- Simultaneous optimization of multiple subgraphs can yield additional gains.

## Related Work

Ansor improves upon existing search-based tensor program generation methods (e.g., TVM's AutoTVM) by expanding the search space and using more effective exploration strategies. It is positioned as a general framework that can find programs outside the search space of prior approaches.

## Open Questions

How does Ansor scale to very large models or extremely complex operators? Can the learned cost model generalize across different hardware generations without retraining? Further exploration of the scheduler's impact on multi-network optimization.
