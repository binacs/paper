# Ansor : Generating High-Performance Tensor Programs for Deep Learning

## TL;DR

Ansor is a tensor program generation framework that uses hierarchical search space sampling, evolutionary search, and a learned cost model to automatically generate high-performance tensor programs for deep learning, outperforming existing approaches on CPU and GPU.

## Problem & Motivation

Deep learning models require efficient tensor programs for various operators and hardware platforms. Current approaches rely on vendor libraries (high engineering cost) or search-based methods that are limited by restricted search spaces and ineffective exploration, often missing high-performance programs.

## Key Ideas

- Hierarchical representation of the search space to sample diverse programs.
- Evolutionary search with a learned cost model to fine-tune sampled programs.
- A scheduler to simultaneously optimize multiple subgraphs across a set of neural networks.

## System Design

Ansor first constructs a hierarchical search space covering loop structures, tiling, and other transformations. It samples programs from this space, then applies evolutionary search guided by a learned cost model to iteratively improve performance. A scheduler coordinates optimization across multiple subgraphs in a model or set of models.

## Evaluation

Evaluated on Intel CPU, ARM CPU, and NVIDIA GPU with various deep neural networks. Achieves speedups up to 3.8×, 2.6×, and 1.7× respectively compared to state-of-the-art approaches.

## Takeaways

- Hierarchical search space enables exploration of more optimization combinations.
- Combining sampling, evolutionary search, and learned cost model is effective.
- Joint optimization of multiple subgraphs yields additional gains.

## Related Work

Ansor improves upon prior search-based tensor program generation methods (e.g., TVM's AutoTVM) by expanding the search space and using more effective exploration strategies.

## Open Questions

Scalability to very large models and more complex hardware; integration with dynamic shapes; further improvements in cost model accuracy.
