# Reducing Activation Recomputation in Large Transformer Models

## TL;DR

This paper introduces sequence parallelism and selective activation recomputation to nearly eliminate activation recomputation in large transformer training, reducing activation memory by 5x and cutting recomputation overhead by over 90%, enabling faster training of trillion-parameter models.

## Problem & Motivation

Training large transformer models is memory-intensive, especially due to storing activations for backpropagation. To fit within GPU memory constraints, activation recomputation is commonly used, where activations are recomputed during backward pass instead of stored, trading compute for memory. However, this adds significant redundant compute, slowing down training. The challenge is to reduce memory consumption without incurring the full recomputation overhead.

## Key Ideas

- Sequence parallelism: Partition the sequence dimension across GPUs to reduce activation memory per GPU, complementing tensor parallelism.
- Selective activation recomputation: Instead of recomputing all activations, selectively store only the most memory-intensive activations (e.g., those after attention and MLP blocks) and recompute the rest, balancing memory and compute.
- Combining sequence parallelism and selective activation recomputation with tensor parallelism to almost eliminate the need for full activation recomputation.

## System Design

The system is built on Megatron-LM, a framework for training large transformer models using tensor parallelism. The proposed techniques are integrated into the training pipeline: sequence parallelism splits the sequence dimension across GPUs, reducing activation memory per GPU. Selective activation recomputation decides which activations to store and which to recompute based on memory and compute trade-offs. The control flow involves forward pass storing selected activations, backward pass recomputing others, and communication for sequence parallelism. Data flow is distributed across GPUs with tensor and sequence parallelism.

## Evaluation

The paper evaluates on language models up to 1 trillion parameters. They show activation memory reduction by 5x and reduction in execution time overhead from activation recomputation by over 90%. For a 530B parameter GPT-3 style model on 2240 NVIDIA A100 GPUs, they achieve 54.2% Model Flops Utilization, which is 29% faster than the 42.1% with recomputation.

## Takeaways

- Activation recomputation is a major bottleneck; reducing it can significantly speed up training.
- Sequence parallelism is a simple yet effective way to reduce activation memory.
- Selective activation recomputation offers a fine-grained trade-off between memory and compute.
- Combining these techniques with tensor parallelism can nearly eliminate recomputation overhead, enabling efficient training of trillion-parameter models.

## Related Work

The paper builds on Megatron-LM's tensor parallelism and addresses the memory constraints that lead to activation recomputation. It positions itself against prior work that uses full activation recomputation, showing that most of the recompute is unnecessary.

## Open Questions

- How do these techniques scale to even larger models and different architectures?
- What is the optimal selection strategy for selective activation recomputation across different model sizes and hardware?
- Can these techniques be combined with other memory optimization methods like offloading or gradient checkpointing?
- The paper focuses on training; how do these techniques apply to inference or fine-tuning?
