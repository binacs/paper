# Reducing Activation Recomputation in Large Transformer Models

## TL;DR

This paper reduces activation recomputation overhead in large transformer training by introducing sequence parallelism and selective activation recomputation, achieving 5x memory reduction and over 90% less recomputation overhead.

## Problem & Motivation

Training large transformer models requires significant memory for storing activations during backpropagation. To fit within GPU memory constraints, activation recomputation (checkpointing) is commonly used, which trades compute for memory by recomputing activations instead of storing them. This adds redundant computation and slows down training. The paper addresses the challenge of reducing this redundant compute while maintaining memory efficiency.

## Key Ideas

- Sequence parallelism: Partition the sequence dimension across devices to reduce per-device activation memory.
- Selective activation recomputation: Only recompute a subset of activations that are expensive to store, rather than all.
- Combine with tensor parallelism to nearly eliminate full activation recomputation.

## System Design

The system extends Megatron-LM's tensor parallelism with two new techniques. Sequence parallelism splits the sequence length across GPUs, reducing activation memory per GPU. Selective activation recomputation identifies which activations to recompute (e.g., those with high memory cost but low compute cost) and stores the rest. The control flow involves forward pass with partial storage, then recomputation of selected activations during backward pass.

## Evaluation

Evaluated on language models up to 1 trillion parameters. On a 530B parameter GPT-3 style model with 2240 NVIDIA A100 GPUs, the method achieves 54.2% Model Flops Utilization (MFU), which is 29% faster than the 42.1% MFU with standard recomputation. Activation memory reduced by 5x, and execution time overhead from recomputation reduced by over 90%.

## Takeaways

- Sequence parallelism is a simple yet effective way to reduce activation memory.
- Selective recomputation avoids unnecessary compute by only recomputing a small fraction of activations.
- Combining these techniques with tensor parallelism can almost eliminate activation recomputation overhead.
- The approach scales to trillion-parameter models and yields significant speedups.

## Related Work

Builds on Megatron-LM's tensor parallelism and standard activation recomputation. Related to other memory reduction techniques like gradient checkpointing and pipeline parallelism, but focuses on reducing recomputation overhead specifically.

## Open Questions

- How does the method perform on other architectures (e.g., encoder-only models)?
- Can selective recomputation be automated or learned?
- Impact on training stability or convergence not discussed.
- Applicability to other parallelism strategies (e.g., data parallelism, pipeline parallelism) beyond tensor parallelism.
