# Reducing Activation Recomputation in Large Transformer Models

## TL;DR

Proposes sequence parallelism and selective activation recomputation to reduce memory usage and eliminate most recomputation overhead in large transformer training, achieving 5x activation memory reduction and over 90% less recomputation overhead.

## Problem & Motivation

Training large transformer models requires significant memory for storing activations during backpropagation. To fit models into GPU memory, activation recomputation (checkpointing) is commonly used, which saves memory but adds redundant compute, slowing down training. The paper addresses the challenge of reducing this redundant compute while maintaining memory efficiency.

## Key Ideas

- Sequence parallelism: Partition the sequence dimension across devices to reduce per-device activation memory.
- Selective activation recomputation: Only recompute a subset of activations that are expensive to store, rather than all.
- Combine with tensor parallelism to nearly eliminate the need for full activation recomputation.

## System Design

The system builds on Megatron-LM's tensor parallelism. Sequence parallelism splits the input sequence along the sequence dimension across GPUs, reducing activation memory per GPU. Selective activation recomputation identifies which activations to recompute (e.g., those with high memory cost but low compute cost) and stores the rest. The combination allows most activations to be stored rather than recomputed.

## Evaluation

Evaluated on language models up to 1 trillion parameters. On a 530B parameter GPT-3 style model with 2240 NVIDIA A100 GPUs, activation memory reduced by 5x, execution time overhead from recomputation reduced by over 90%, achieving 54.2% Model Flops Utilization (29% faster than 42.1% with recomputation).

## Takeaways

- Sequence parallelism is a simple yet effective technique to reduce activation memory.
- Selective recomputation can eliminate most redundant compute without increasing memory.
- Combining these techniques with tensor parallelism yields significant speedups for large model training.

## Related Work

Builds on Megatron-LM's tensor parallelism and prior activation recomputation techniques. The paper positions itself as improving upon standard recomputation by showing most of it is unnecessary.

## Open Questions

How do these techniques interact with other parallelism strategies (e.g., pipeline parallelism)? Can selective recomputation be automated or learned? Applicability to other architectures beyond transformers?
